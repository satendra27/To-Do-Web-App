# Full Stack To-Do Web App

A full stack task management application where users can create boards and manage todos inside them.

## 🚀 Features
- User registration and login with JWT authentication
- Create, update, and delete boards
- Create, update, delete, and complete todos inside boards
- Protected routes and secure access
- Modern, responsive UI with real-time feedback

---

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Notifications:** react-hot-toast

---

## ⚙️ Setup Instructions

## Backend Setup

### Follow the steps below to run the backend server.

1. Navigate to the backend folder
```
cd backend
```

2. Install backend dependencies
```
npm install
```

3. Start the backend server
```
npm run server
```

4. Backend will run on
```
http://localhost:5000
```

## Frontend Setup

### Follow the steps below to run the frontend application.

1. Navigate to the frontend folder:
```
cd frontend
```

2. Install frontend dependencies:
```
npm install
```

3. Start the frontend development server:
```
npm run dev
```

4. Frontend will run on:
```
http://localhost:5173
```
